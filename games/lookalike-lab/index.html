Lookalike Lab

Read the clues, then decide: venomous or harmless? Each round has 8 snakes drawn from our region-by-region venomous or not ID guide, and every answer comes with a fact card so you learn which features matter.

For learning only. This game is not safety advice. Many harmless snakes mimic dangerous ones, and colour and pattern vary. Never use this game, or any website, to decide whether a real snake is safe. Keep your distance from all wild snakes, and if a bite may have happened, call your local emergency number straight away.

What this game teaches

  • Which features the ID guide uses for each region, such as rattles, heat pits, hoods, band order and pupil shape.
  • That harmless lookalikes exist almost everywhere (gopher snakes, milk snakes, rat snakes, wolf snakes, bush snakes).
  • That some rules only work in one place: the coral snake colour rhyme applies to US species only.
